# 不完善之处与改进路线

本页列出代码审查发现的限制和仍需验证的部分。发布源码是为了交流与改进，不把原型包装为完成品。

| 问题 | 当前状态 / 影响 | 后续方向 |
|---|---|---|
| 中文唤醒词 | 预置为 Hey Jarvis；「丽萨」唤醒训练未完成 | 公开训练流程、中文样本和误唤醒评测 |
| 声纹 | 未完成个人声纹能力；不分发私人样本 | 录入、删除、阈值与误识别测试 |
| 语音打断与噪声 | 软件取消与流式接口存在，真实声学效果仍待验收 | 回声、误打断、麦克风和延迟实测 |
| 桌面操作稳定性 | 应用 UI/焦点/DPI/坐标变化影响结果 | 优先稳定元素定位和操作后验证 |
| 音乐控制 | 部分动作依赖窗口坐标 | 覆盖应用版本与分辨率变化 |
| 离线体验 | 云模型、Edge TTS、搜索、天气需联网；备用模型需配置 | 完整本地链路和断网故障测试 |
| 硬件离线应答 | 板端只转写、简单问候/报时并记日志，没有完整 LLM 或离线 TTS | 补足端侧推理与播放链路 |

| 板卡适配 | 当前代码主要针对 Orange Pi 5 Pro/RK3588S，旧资料混有 4 Pro/A733 | 分板卡 GPIO/SPI 配置、实机验证 |
| 终端端口 | 旧配置默认 8080，bridge 默认 8765 | 本次公开配置已统一为 8765，仍需正确 host/token |
| 文档解析 | 基础提取；PDF 使用的 pypdf 未列入 pyproject 依赖 | 整理可选依赖、增加格式验证 |
| LoRA 可移植性 | 示例脚本仍含 `D:\jarvis-training` 路径 | 参数化路径、独立环境与可复现评测 |
| 长任务和长期运行 | 尚未完成本次 30/60/120 分钟稳定性实测 | 异常恢复、资源泄漏和并发任务测试 |
| 模型一致性 | 各服务的工具调用、视觉、reasoning 参数不同 | 兼容矩阵、失败策略和端到端评测 |
| 首次安装与更新 | 源码需配置依赖和模型；缺少正式分发和更新渠道 | 干净机器安装验收、签名与发布流水线 |
| 跨平台 | Windows 是主要目标，其余平台未做同等验收 | 分平台能力表与 CI |

## 本次发布做了什么

整理公开说明、保留当前源码、剔除私人配置与数据、统一终端示例端口，并调整打包脚本避免复制本机 `.env`。这些调整不等于上表功能全部补完。测试与构建中的实际问题记录在 [VALIDATION.md](VALIDATION.md)。

## 优先改进方向

1. 首次安装与配置诊断：让新用户用明确步骤跑通文字、语音、桌面三条链路。
2. 中文语音体验：真实测量延迟、回声和打断效果，完成中文唤醒评测。
3. 可靠执行：给桌面动作增加可观察验证，完善异常恢复与长期稳定性。
4. 硬件终端：先确定板卡与引脚映射，再补 OLED、离线 TTS 和端侧推理。
5. 工程化：依赖整理、跨平台测试、自动更新与可复现发布。

路线图表示希望推进的方向，不承诺日期。欢迎指出优先级是否合理，或者分享相似问题的实践经验。
